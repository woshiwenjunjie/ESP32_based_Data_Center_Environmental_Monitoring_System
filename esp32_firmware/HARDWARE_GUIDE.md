## 🔌 详细连接说明

### 从机硬件连接

#### 1. DHT11/DHT22 温湿度传感器

```
DHT11/DHT22 引脚    ESP32 引脚
─────────────────────────────────
VCC  (电源正)   →   3.3V 或 5V
GND  (电源负)   →   GND
DATA (数据)     →   GPIO21
NC   (空脚)     →   悬空（4针版本）
```

**注意事项：**
- DHT11和DHT22引脚兼容，DHT22精度更高
- 数据引脚建议串联10KΩ上拉电阻（部分模块已集成）
- 两个传感器读取间隔需大于2秒

#### 2. MQ-2 烟雾/气体传感器

```
MQ-2 模块引脚      ESP32 引脚
─────────────────────────────────
VCC  (电源正)   →   5V  ⚠️ 必须5V供电
GND  (电源负)   →   GND
AO   (模拟输出) →   GPIO36 (VP)
DO   (数字输出) →   GPIO16
```

**注意事项：**
- ⚠️ **必须5V供电**，3.3V无法驱动加热丝
- 首次使用需预热1-2分钟才能达到稳定状态
- 模块上的蓝色电位器可调节数字输出阈值
- 模拟输出值范围：0-4095（12位ADC）

#### 3. 水位传感器

```
水位传感器引脚     ESP32 引脚
─────────────────────────────────
VCC  (电源正)   →   3.3V 或 5V
GND  (电源负)   →   GND
AO   (模拟输出) →   GPIO32
```

**注意事项：**
- 传感器有多个检测点，水位越高输出值越大
- 完全干燥时输出接近0，完全浸入时输出接近4095
- 可根据实际应用场景校准水位与ADC值的对应关系

#### 4. OLED显示屏（I2C）

```
OLED 引脚         ESP32 引脚
─────────────────────────────────
VCC  (电源正)   →   3.3V
GND  (电源负)   →   GND
SCL  (时钟)     →   GPIO22
SDA  (数据)     →   GPIO21
```

**注意事项：**
- 确认OLED地址（通常为0x3C或0x3D）
- 如显示异常，检查I2C接线是否牢固

### 主机硬件连接

#### 1. OV3660 摄像头模块

```
OV3660 引脚       ESP32-S3 引脚
─────────────────────────────────
VCC    (电源正)  →   3.3V
GND    (电源负)  →   GND
SIOC   (I2C时钟) →   GPIO5
SIOD   (I2C数据) →   GPIO4
VSYNC  (帧同步)  →   GPIO6
HREF   (行同步)  →   GPIO7
PCLK   (像素时钟)→   GPIO13
XCLK   (系统时钟)→   GPIO15
D0-D7  (数据位)  →   GPIO8-12, GPIO16-18
```

**注意事项：**
- 摄像头对电源质量要求较高，确保3.3V稳定
- 数据线尽量短，减少干扰
- 首次使用可能需要校准焦距

#### 2. OLED显示屏（I2C）

```
OLED 引脚         ESP32-S3 引脚
─────────────────────────────────
VCC  (电源正)   →   3.3V
GND  (电源负)   →   GND
SCL  (时钟)     →   GPIO22
SDA  (数据)     →   GPIO21
```

#### 3. 继电器模块

```
继电器模块引脚     ESP32-S3 引脚
─────────────────────────────────
VCC  (电源正)   →   5V
GND  (电源负)   →   GND
IN   (控制信号) →   GPIO45
```

**注意事项：**
- 继电器输出端可接220V交流负载（注意安全！）
- 控制信号为低电平触发或高电平触发，根据模块确认
- 大电流负载建议使用独立电源供电

#### 4. 蜂鸣器

```
蜂鸣器引脚        ESP32-S3 引脚
─────────────────────────────────
VCC  (电源正)   →   5V
GND  (电源负)   →   GND
I/O  (控制信号) →   GPIO40
```

**注意事项：**
- 无源蜂鸣器：使用PWM驱动，可控制频率（100-10000Hz）
- 有源蜂鸣器：高低电平控制，通电即响
- 本项目使用无源蜂鸣器，支持频率调节

#### 5. SG90 舵机

```
舵机引脚          ESP32-S3 引脚
─────────────────────────────────
红色 (电源正)   →   5V  ⚠️ 必须5V
棕色 (电源负)   →   GND
橙色 (信号)     →   GPIO20
```

**注意事项：**
- ⚠️ **必须5V供电**，3.3V无法提供足够扭矩
- 控制角度范围：0-180度
- PWM频率：50Hz（周期20ms），脉宽0.5-2.5ms

#### 6. 直流电机 + 驱动模块（如L298N）

```
电机驱动模块引脚   ESP32-S3 引脚
─────────────────────────────────
ENA  (使能A)    →   GPIO19 (PWM调速)
IN1  (输入1)    →   GPIOxx (方向控制)
IN2  (输入2)    →   GPIOxx (方向控制)
VCC  (电机电源) →   外部电源（根据电机电压）
GND  (共地)     →   GND
```

**注意事项：**
- 电机电源根据电机规格选择（如12V）
- 电机驱动模块GND必须与ESP32共地
- PWM调速范围：0-255

## ⚡ 电源要求

### 从机供电
- **输入电压**: 5V（通过USB或外部电源）
- **电流需求**: 约200-300mA（正常工作）
- **传感器供电**:
  - DHT11: 3.3V-5V, 约2.5mA
  - MQ-2: 必须5V, 约150mA（加热丝耗电）
  - 水位传感器: 3.3V-5V, 约5mA
  - OLED: 3.3V, 约20mA

### 主机供电
- **输入电压**: 5V（通过USB或外部电源）
- **电流需求**: 约500-800mA（摄像头工作时）
- **建议使用**: 2A以上电源适配器
- **外设供电**:
  - 继电器: 5V, 约70mA
  - 蜂鸣器: 5V, 约30mA
  - 舵机: 5V, 约100-250mA（动作时）
  - 电机: 根据电机规格独立供电

## 🔧 故障排查

| 故障现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| DHT读取失败 | 接线松动 | 检查VCC、GND、DATA接线 |
| | 上拉电阻缺失 | 添加10KΩ上拉电阻 |
| | 读取过于频繁 | 间隔需大于2秒 |
| MQ-2数值不稳定 | 预热不足 | 等待1-2分钟预热 |
| | 供电不足 | 确保5V供电稳定 |
| 水位传感器无输出 | 传感器损坏 | 更换传感器 |
| | 接触不良 | 检查接线 |
| OLED不显示 | I2C地址错误 | 确认地址是0x3C还是0x3D |
| | 接线错误 | 检查SCL/SDA接线 |
| 摄像头画面花屏 | 电源不稳 | 使用独立稳压电源 |
| | 数据线过长 | 缩短数据线长度 |
| 舵机不转 | 供电不足 | 确保5V供电，电流≥200mA |
| | 信号线接错 | 检查GPIO引脚 |

## 📝 备注

1. **GPIO引脚分配**可根据实际情况调整，修改对应代码中的引脚定义即可
2. **电源质量**对系统稳定性影响很大，建议使用稳压电源
3. **接线牢固性**很重要，松动的接线会导致随机故障
4. **静电防护**处理传感器时注意静电，避免损坏敏感元件
