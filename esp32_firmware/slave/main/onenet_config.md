# OneNet 平台配置说明

> **快速开始**：本文档指导您如何将ESP32从机连接到中国移动OneNet物联网平台，实现传感器数据云端存储和可视化。

## 【使用流程概览】

```
1. 注册OneNet账号 → 2. 创建产品 → 3. 添加设备 → 4. 配置数据点 → 5. 获取三要素 → 6. 填写到config.h → 7. 编译上传 → 8. 查看数据
```

## 【前置条件】

- 已注册OneNet平台账号
- ESP32从机已能正常采集传感器数据
- 已安装Arduino IDE并配置好ESP32开发环境

## 一、传感器数据类型

| 数据点名称 | 数据类型 | 单位 | 取值范围 | 说明 |
|-----------|---------|------|---------|------|
| `temperature` | float | °C | -40.0 ~ 85.0 | 温度值，保留1位小数 |
| `humidity` | float | %RH | 0.0 ~ 100.0 | 湿度值，保留1位小数 |
| `smoke_status` | int | - | 0 或 1 | 烟雾状态（0=报警，1=正常） |
| `gas_value` | int | - | 0 ~ 4095 | 气体浓度（ADC值） |
| `water_level` | int | - | 0 ~ 4095 | 水位值（ADC值） |

## 二、OneNet 平台配置步骤

### 1. 注册/登录 OneNet 平台
- 访问 [OneNet 官网](https://open.iot.10086.cn/)
- 注册或登录账号

### 2. 创建产品
1. 进入控制台 → 产品管理 → 创建产品
2. 填写产品信息：
   - 产品名称：ESP32 传感器采集站
   - 行业：智能硬件
   - 设备类型：ESP32
   - 网络类型：WiFi
   - 数据协议：MQTT
3. 点击「创建」

### 3. 添加设备
1. 进入产品详情页 → 设备管理 → 添加设备
2. 填写设备信息：
   - 设备名称：esp32_slave
   - 认证信息：自动生成或自定义
3. 点击「添加」

### 4. 配置数据点
1. 进入产品详情页 → 物模型管理
2. 点击「添加属性」，依次添加以下数据点：

| 数据点名称 | 数据类型 | 单位 | 读写类型 |
|-----------|---------|------|----------|
| temperature | float | °C | 只读 |
| humidity | float | % | 只读 |
| smoke_status | int | - | 只读 |
| gas_value | int | - | 只读 |
| water_level | int | - | 只读 |

### 5. 获取三要素
1. 进入产品详情页 → 设备管理
2. 点击设备名称进入设备详情
3. 获取以下信息：
   - **产品ID** (product_id)
   - **设备名称** (device_name)
   - **设备密钥** (device_secret) - 点击「查看」获取

## 三、代码配置

### 1. 填写 OneNet 三要素
编辑 `config.h` 文件，填写你的 OneNet 平台信息：

```cpp
// ============== WIFI和MQTT配置 ==============
// ⚠️ 请填写你的 OneNet 平台三要素
#define WIFI_SSID      "YOUR_WIFI_SSID"              // WiFi名称
#define WIFI_PASSWORD  "YOUR_WIFI_PASSWORD"          // WiFi密码

#define MQTT_SERVER    "mqtts.heclouds.com"          // MQTT服务器地址
#define MQTT_PORT      1883                          // MQTT端口
#define PRODUCT_ID     "YOUR_PRODUCT_ID"             // 产品ID
#define DEVICE_NAME    "YOUR_DEVICE_NAME"            // 设备名称
#define DEVICE_SECRET  "YOUR_DEVICE_SECRET"          // 设备密钥
```

### 2. 数据上报格式

上报的 JSON 格式示例：

```json
{
  "id": "123456789",
  "version": "1.0",
  "params": {
    "temperature": { "value": 25.5 },
    "humidity": { "value": 60.2 },
    "smoke_status": { "value": 1 },
    "gas_value": { "value": 1200 },
    "water_level": { "value": 850 }
  }
}
```

## 五、故障排查

### 常见问题及解决方案

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| **WiFi连接失败** | WiFi名称或密码错误 | 检查config.h中的WIFI_SSID和WIFI_PASSWORD |
| | WiFi是5GHz频段 | ESP32只支持2.4GHz，请切换WiFi频段 |
| | WiFi信号弱 | 将设备靠近路由器测试 |
| **MQTT连接失败** | 三要素填写错误 | 检查PRODUCT_ID、DEVICE_NAME、DEVICE_SECRET |
| | 设备未激活 | 在OneNet平台确认设备状态为"激活" |
| | 网络防火墙 | 确保网络允许访问mqtts.heclouds.com:1883 |
| **数据上报失败** | 数据点名称不匹配 | 检查OneNet平台数据点名称与代码中一致 |
| | 数据格式错误 | 查看串口输出确认JSON格式正确 |
| **数据不显示** | 物模型未配置 | 确保在OneNet平台添加了对应的数据点 |
| | 数据类型不匹配 | 检查数据类型（float/int）是否一致 |

### 调试信息查看
- **串口输出**：连接串口监视器（波特率115200）查看详细日志
- **OneNet平台**：进入设备详情 → 设备日志查看连接状态
- **数据流**：进入设备详情 → 数据流查看实时数据

## 六、注意事项

1. **安全**：设备密钥是敏感信息，不要分享给他人，不要提交到公共仓库
2. **频率**：默认每5秒上报一次数据，可根据需要在config.h中调整SEND_INTERVAL
3. **稳定性**：确保WiFi网络稳定，避免频繁断连导致数据丢失
4. **流量**：注意MQTT上报的流量消耗，频繁上报可能产生较多流量
5. **免费额度**：OneNet平台有免费额度限制，超出后可能需要付费
